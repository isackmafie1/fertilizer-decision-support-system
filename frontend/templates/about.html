About This System

Fertilizer Decision Support System

A data-driven system for balanced fertilizer recommendations for maize production in Mbeya Region, Tanzania.

Problem

Smallholder maize farmers in Mbeya apply fertilizers without proper soil testing, leading to over-application, under-application, and financial losses. Most farmers lack access to soil testing equipment and the technical knowledge to interpret laboratory results.

Solution

This system uses Machine Learning to analyze soil data and recommend the correct fertilizer type and dosage for each farm's specific soil conditions, putting accurate agronomic intelligence directly into the hands of Agricultural Extension Officers.

Who Uses This System
Agricultural Extension Officer

The primary user of this system. The officer visits farms, collects soil samples, sends them to TARI Uyole for laboratory testing, enters the results into this system, and receives an instant fertilizer recommendation with the correct dosage.

Smallholder Farmer

The final beneficiary of the system. The farmer does not interact with the system directly, but receives the fertilizer recommendation and application guidance through their extension officer, in simple language they understand.

How It Works — Step by Step
1 Extension officer visits the farm and collects a soil sample
2 Sample is sent to TARI Uyole Agricultural Centre for testing
3 Officer enters the lab results (N, P, K, pH) into this system
4 The system instantly returns the recommended fertilizer and dosage
5 Officer explains the recommendation to the farmer in simple terms
Model Information
Algorithm

Random Forest Classifier

Accuracy

95.62%

Dataset

4,998 soil records — Mbeya Region

Districts Covered

Busokelo, Chunya, Kyela, Mbarali, Mbeya Rural, Rungwe
